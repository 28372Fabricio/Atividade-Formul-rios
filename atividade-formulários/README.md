# Atividade-Formul-rios

## Como rodar o projeto

1. Abra o terminal na pasta do projeto.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o projeto em modo de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse a URL exibida no terminal, normalmente:
   ```bash
   http://localhost:5173
   ```

## Sobre

Projeto simples de formulário em React com validação básica.
